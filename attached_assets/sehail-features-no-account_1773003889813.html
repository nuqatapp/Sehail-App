✦ ميزات بدون حساب

كل شيء يتخزن على جوال المستخدم — بدون تسجيل، بدون إنترنت، بدون سيرفر

القاعدة: افتح واستخدم

كل الميزات تشتغل من أول ثانية. ما فيه شاشة تسجيل. ما فيه إيميل. ما فيه كلمة مرور. البيانات تتخزن على الجوال فقط باستخدام AsyncStorage. لو المستخدم حذف التطبيق = تنمسح. لو أعاد تثبيته = يبدأ من جديد. هذا مقبول — التطبيق أداة سلامة مو منصة اجتماعية.

التشيك ليست التفاعلية

☑️ تشيك ليست تتذكر

سهل
المستخدم يضغط على كل عنصر لما يجهّزه. التطبيق يحفظ العناصر المحددة ويعرض شريط تقدم (٧ من ١٢). لما يفتح التطبيق مرة ثانية = يلقى تقدّمه محفوظ.
يتخزن: مصفوفة IDs للعناصر المحددة لكل قائمة
مثال: checklist_vehicle: ["fuel","tires","water","tools"]
حجم: أقل من 1KB

🔄 زر إعادة تعيين

سهل
زر "رحلة جديدة" يمسح كل التحديدات ويرجّع القائمة للصفر. المستخدم يبدأ تجهيز جديد كل رحلة.
يتخزن: لا شيء إضافي — يمسح البيانات المحفوظة
حجم: 0

📊 عدّاد الرحلات

سهل
كل مرة المستخدم يكمّل تشيك ليست ويضغط "إعادة تعيين"، العدّاد يزيد ١. "أكملت ٥ رحلات بتجهيز كامل". رقم بسيط يعطي إحساس بالإنجاز.
يتخزن: رقم واحد
مثال: trips_completed: 5
حجم: بضع بايتات
نصيحة اليوم التفاعلية

💡 "عرفتها" أو "معلومة جديدة"

سهل
بدل بانر ساكن، النصيحة تعرض زرين: "أيوا عارفها ✅" و "معلومة جديدة 💡". المستخدم يضغط واحد. التطبيق يحفظ إجابته ويعرض النصيحة التالية بكرا.
يتخزن: آخر نصيحة مقروءة + تاريخ + إجابة
مثال: tip_last: {id:47, date:"2026-03-09", answer:"new"}
حجم: أقل من 1KB

🔥 سلسلة التعلّم (Streak)

سهل
لو المستخدم قرأ النصيحة كل يوم = السلسلة تزيد. لو فات يوم = ترجع صفر. "سلسلة ١٢ يوم 🔥". نفس فكرة Duolingo — بدون حساب.
يتخزن: عدد أيام السلسلة + تاريخ آخر زيارة
مثال: streak: {count:12, lastDate:"2026-03-09"}
حجم: أقل من 1KB

📈 عدّاد المعرفة

سهل
"تعلمت ٣٤ معلومة جديدة" — كل مرة المستخدم يضغط "معلومة جديدة" العدّاد يزيد. رقم بسيط يعطي شعور بالتراكم.
يتخزن: رقم واحد
مثال: new_tips_count: 34
حجم: بضع بايتات
الكويز

❓ كويز قصير بعد كل قسم

متوسط
٥-١٠ أسئلة اختيار من متعدد بعد كل قسم رئيسي. "وش أول شيء تسويه لو لدغك عقرب؟" الأسئلة مخزنة في ملف البيانات مع المحتوى. النتيجة تتحفظ محلياً.
يتخزن: أعلى نتيجة لكل كويز
مثال: quiz_safety: {best:8, total:10, date:"2026-03-09"}
حجم: أقل من 1KB

🎯 إعادة المحاولة

سهل
لو ما جبت ١٠٠٪ = زر "حاول مرة ثانية". التطبيق يحفظ أعلى نتيجة بس. يخلّي المستخدم يبي يرجع ويحسّن.
يتخزن: مشمول في النقطة السابقة
الإنجازات (Badges)

🏆 شارات الإنجاز

متوسط
شارات تُفتح تلقائياً لما المستخدم يحقق شروطها. كل شارة لها اسم عربي وأيقونة. تُعرض في صفحة "إنجازاتي" أو في الصفحة الرئيسية.
يتخزن: مصفوفة IDs الشارات المفتوحة + تاريخ الفتح
مثال: badges: ["desert_ready","navigator","first_aid_pro"]
حجم: أقل من 1KB

📋 قائمة الشارات المقترحة

سهل
جاهز للبر 🏜️ — كمّل تشيك ليست بر كاملة
جاهز للبحر 🌊 — كمّل تشيك ليست بحر كاملة
ملاّح ✦ — قرأ كل محتوى دليل الملاحة
مسعف أولي 🏥 — نجح في كويز السلامة ١٠٠٪
عارف البر 🦂 — قرأ كل بطاقات الكائنات
صاحب سوالف 💧 — قرأ ١٠ سوالف
متعلّم يومي 🔥 — سلسلة ٧ أيام نصيحة
محترف 🔥🔥 — سلسلة ٣٠ يوم نصيحة
مستكشف ⭐ — فتح كل الشارات الثانية
يتخزن: مشمول في النقطة السابقة — الشروط محسوبة من البيانات المحلية
أدوات الطوارئ

📋 رسالة طوارئ جاهزة للنسخ

سهل
نص رسالة جاهز بالعربي فيه فراغات يعبّيها المستخدم. زر "انسخ" ينسخ الرسالة للكليبورد. زر "أرسل واتساب" يفتح واتساب مباشرة بالرسالة.
يتخزن: لا شيء — النص يتولّد في اللحظة
يستخدم: Clipboard API + Linking.openURL لفتح واتساب

📍 زر شارك موقعك

متوسط
زر واحد يقرأ GPS الجوال ويفتح share sheet بالإحداثيات أو رابط خريطة. يشتغل بدون إنترنت — GPS يعطيك إحداثيات حتى بدون شبكة.
يتخزن: لا شيء
يستخدم: expo-location + expo-sharing أو Share API

⚡ بطاقات أول ٥ دقائق

سهل
كل سالفة سلامة لها نسخة طوارئ: خطوات مرقّمة كبيرة واضحة. الخطوة الحالية بارزة باللون الأخضر. زر "اتصل 911" دائماً ظاهر في الأسفل.
يتخزن: لا شيء — المحتوى موجود في ملف البيانات
يستخدم: نفس البيانات الحالية بتصميم مختلف

⏱️ مؤقت الأمان (Safety Timer)

متقدم
المستخدم يحدد: "بارجع الساعة ٨ مساء". لو ما فتح التطبيق بعد الوقت المحدد = التطبيق يرسل SMS تلقائي بآخر موقع لرقم طوارئ حدده المستخدم مسبقاً.
يتخزن: وقت العودة + رقم جهة الاتصال + آخر موقع
مثال: safety_timer: {return:"20:00", contact:"+966...", lat:24.7, lng:46.6}
يستخدم: expo-notifications (local) + expo-sms
ملاحظة: يحتاج إذن المستخدم لإرسال SMS + تشغيل في الخلفية
أدوات الملاحة

🧭 بوصلة مدمجة

متوسط
بوصلة حقيقية تقرأ حساس المغناطيس في الجوال. تُعرض داخل صفحة دليل الملاحة. تشتغل بدون إنترنت.
يتخزن: لا شيء
يستخدم: expo-sensors (Magnetometer) — مجاني ومدمج في Expo

📌 حفظ نقطة الانطلاق

متوسط
زر "سجّل مكاني" يحفظ إحداثيات GPS الحالية. يعرضها بعدين كـ "نقطة الانطلاق: 24.7136°N 46.6753°E". زر "ارجع لنقطة الانطلاق" يفتح خرائط الجوال بالإحداثيات المحفوظة.
يتخزن: إحداثيات + وقت + اسم اختياري
مثال: saved_points: [{name:"المخيم", lat:24.7, lng:46.6, time:"15:30"}]
حجم: أقل من 1KB
الوصول السريع

🔍 "تعرّف بسرعة" — وش شفت؟

سهل
أزرار كبيرة في الصفحة الرئيسية: عقرب 🦂 / ثعبان 🐍 / قنديل 🪼 / نبتة 🌵. ضغطة وحدة = يوصل لبطاقة التعريف + "وش تسوي". مسار اختصار — ما يحتاج تتصفح.
يتخزن: لا شيء — مسار تنقل فقط
يستخدم: React Navigation مع params

🔖 المفضلة

سهل
أيقونة قلب أو نجمة على أي بطاقة (كائن، سالفة، نصيحة). المستخدم يضغطها = تنحفظ في قائمة "مفضلاتي". يقدر يوصلها بسرعة بدون ما يبحث.
يتخزن: مصفوفة IDs المفضلة
مثال: favorites: ["creature_scorpion","story_snakebite","tip_42"]
حجم: أقل من 1KB
المشاركة

📤 شارك جاهزيتك

متوسط
لما يكمّل التشيك ليست = زر "شارك". يولّد رسالة نصية: "أنا جاهز لرحلة البر — جهّزت ١٢ من ١٢ عنصر عبر تطبيق سهيل ✦". يفتح share sheet الجوال (واتساب، سناب، رسائل).
يتخزن: لا شيء
يستخدم: Share API (React Native مدمج)

📤 شارك نتيجة الكويز

سهل
"جبت ٩ من ١٠ في كويز السلامة! جرّب تطبيق سهيل ✦". نفس آلية المشاركة — نص جاهز + share sheet.
يتخزن: لا شيء
يستخدم: Share API
تتبع القراءة

👁️ "مقروء" تلقائي

سهل
لما المستخدم يفتح بطاقة كائن أو سالفة = تنحفظ كـ "مقروءة". البطاقات المقروءة تظهر بشكل مختلف (شفافية أخف أو علامة ✓ صغيرة). هذا يعطي إحساس بالتقدم.
يتخزن: مصفوفة IDs المحتوى المقروء
مثال: read_items: ["creature_scorpion","creature_viper","story_camp"]
حجم: أقل من 2KB

📊 "اكتشفت ٦٠٪ من المحتوى"

سهل
شريط تقدم صغير يعرض نسبة المحتوى المقروء. يظهر في الصفحة الرئيسية أو في كل قسم. يحسب من عدد العناصر المقروءة ÷ العدد الكلي.
يتخزن: مشمول في النقطة السابقة — النسبة تُحسب تلقائياً

💾 كل البيانات المحفوظة مجتمعة تأخذ أقل من 10KB على جوال المستخدم. AsyncStorage يقدر يخزن ميغابايتات. أنت تحتاج كيلوبايتات فقط.

📦 المكتبات المطلوبة (كلها مجانية ومدمجة في Expo):

AsyncStorage — تخزين محلي (مثبّت غالباً)
expo-location — GPS للموقع
expo-sensors — بوصلة (Magnetometer)
expo-sharing أو Share — مشاركة واتساب/سناب
expo-clipboard — نسخ رسالة الطوارئ
expo-notifications — تنبيهات محلية (مؤقت الأمان)
expo-sms — إرسال SMS (مؤقت الأمان)
